🎬 Netflix Clone

A full-stack Netflix clone built with React, Firebase, VidSrc API, and the TMDB API, featuring responsive design, user authentication, personalized favorite lists, and accessibility best practices.

🚀 Features

    -Authentication: Email-based sign-up and login (via Firebase).

    -Favorites: Save movies/TV shows to your personal "My List".

    -Movie & TV Show Details: Stream movies, stream shows by picking the season + episode, view runtime, ratings, and more.

    -Carousels: Browse categories with Splide.js carousels (keyboard accessible).

    -Responsive Design: Fully optimized for mobile, tablet, and desktop.

    -Accessibility: ARIA enhancements, keyboard navigation support, visible focus indicators.

    -Tech Stack: React, Next.js, Firebase, TMDB API, VidSrc API, Splide.js, CSS Modules.

📚 Technologies Used

    -React

    -Firebase Authentication

    -TMDB API

    -Splide.js (Carousels)

    -CSS Modules

    -ARIA & Accessibility Best Practices

🛡️ Accessibility Focus

    -ARIA labels on carousels, modals, and forms.

    -Keyboard navigable carousels (Splide.js with keyboard support).

    -Visible focus indicators for all interactive elements.

    -Semantic HTML structure (sections, headings, lists, buttons, etc.).
